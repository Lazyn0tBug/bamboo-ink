# 古籍现代化改造方案

> **项目**: bamboo-ink (古籍现代化改造)  
> **技术栈**: Bun + Astro + Tailwind CSS + Noto Serif SC  
> **创建日期**: 2026-04-10  
> **整理者**: 虾龙 🦐

---

## 📋 项目概述

### 目标

将 `~/data/古籍` 目录中的老旧 HTML 格式古籍文本进行现代化改造，构建一个**可读、可搜、可问**的静态阅读平台。

### 范围

| 维度 | 说明 |
|------|------|
| **数据源** | ~/data/古籍 (约 1000+ HTML 文件) |
| **四部分类** | 经、史、子、集 |
| **输出** | 静态网站，可本地部署 |
| **核心功能** | 多模板阅读、全文搜索、AI 标注、智能问答 |

## 📦 数据转换流程

### HTML → Markdown

```
输入: 老旧 HTML 文件 (GBK 编码)
  ↓
1. 编码转换: GBK → UTF-8
  ↓
2. 结构解析: 提取标题、章节、正文
  ↓
3. 格式转换: HTML → Markdown
  ↓
4. Frontmatter: 生成元数据 (标题、分类、日期)
  ↓
输出: Markdown 文件 (content/经/xxx.md)
```

### 转换脚本

```bash
# 测试转换 (前 10 个文件)
bun run convert

# 批量转换 (全部文件)
bun run scripts/convert-htm-to-md.js --all

# 生成索引
bun run scripts/generate-index.js
```

## 🧠 AI 智能标注

### 标注内容

| 类型 | 说明 | 示例 |
|------|------|------|
| **人物** | 人名、字号、谥号 | 孔子、仲尼、文宣王 |
| **地名** | 古今地名对照 | 长安 → 西安 |
| **典故** | 成语、典故出处 | 刻舟求剑 (吕氏春秋) |
| **时间** | 年号、干支纪年 | 贞观元年 → 627 年 |

### AI 问答

| 功能 | 说明 |
|------|------|
| **文言文翻译** | 文言文 → 白话文 |
| **背景解释** | 典故出处、历史背景 |
| **内容问答** | 基于古籍内容的问答 |

### 技术方案

```javascript
// AI 标注 API (使用 Qwen 模型)
async function annotate(text) {
  const response = await openai.chat.completions.create({
    model: 'Qwen/Qwen2.5-72B-Instruct',
    messages: [{
      role: 'user',
      content: `请标注以下古籍文本中的人物、地名、典故、时间：\n\n${text}`
    }],
    response_format: { type: 'json_object' }
  });
  
  return JSON.parse(response.choices[0].message.content);
}
```

## ⚠️ 风险管理

### 技术风险

| 风险 | 影响 | 概率 | 应对措施 |
|------|------|------|----------|
| 编码转换错误 | 文字乱码 | 中 | 保留原文件备份，逐批转换 |

| 搜索性能差 | 响应慢 | 低 | 索引分片，懒加载 |

| 风险 | 影响 | 概率 | 应对措施 |
|------|------|------|----------|
| 结构丢失 | 章节错乱 | 中 | 人工校对关键章节 |
| 标注错误 | 误导读者 | 中 | AI 标注 + 人工审核 |
| 版权争议 | 法律风险 | 低 | 仅用于个人学习 |

### 进度风险

| 风险 | 影响 | 概率 | 应对措施 |
